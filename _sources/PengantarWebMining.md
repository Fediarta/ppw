# Pencarian dan Penambangan web


## Pengertian web mining


Web Mining adalah Proses menemukan dan mengekstrak informasi dari internet menggunakan teknik penambangan data. web mining mengimplementasikan teknik Data Mining untuk menggali dan mengekstraksi informasi otomatis dari data yang tersimpan di web. namun, web mining memiliki perbedaan dengan data mining karena data web bersifat tidak terstruktur dan tersebar diberbagai sumber. web mining pertama kali dikenalkan oleh Etzioni Oren pada tahun 1996.


## Jenis - Jenis Web Mining

Web Mining  dibagi menjadi 3 bagian utama :

###  Web Content Mining

Web content Mining adalah suatu proses otomatis untuk menemukan informasi yang berguna atau dibutuhkan dari dokumen atau data. Teknik Web Content mining berfokus pada penggalian informasi dari isi (content) web, seperti Teks, gambar, Audio, Video, Metadata dan Hyperlink. Ada 2 strategi yang umum dilakukan :

1. dengan cara menambang langsung terhadap data.

2. dengan cara melakukan pencarian serta mengimprove hasil pencarian seperti search engine.

### Web Structure Mining

Web Structure Mining adalah teknik yang digunakan untuk menemukan struktur link dari hyperlink sehingga diketahui keterkaitan antara suatu halaman web dengan halaman web lainnya. kemudian dari situ dapat dibangun  rangkuman website . kategori ini dari weeb mining berfokus pada penggalian informasi dari isi (content) yang disajikan web.


### Web Usage Mining 

Web Usage Mining adalah teknik yang selalu mengedepankan penggalian pada pola (pattern) dari pengguna dalam mengakses halaman-halaman web yang ditandai dari log, click,stream,cookies, dan query. maafaatnya untuk melakukan perubahan halaman berdasarkan profil pengguna,menentukan ketertarikan pelanggan terhadap produk dan menentukan target market yang sesuai.



## Proses dalam Web mining

1.Pengumpulan data (Data Collection) : data diambil dari berbagai sumber diweb, seperti halaman web, file log server, media sosial, dll.

2.Preprocessing (persiapan data): pembersihan data dan proses agar format data sesuai yang dibutuhkan. contohnya seperti penghapusan data ,mengatasi duplikasi,atau mengubah format.

3. Eksplorasi Data (Data Explorasi) : digunakan untuk menemukan pola atau hubungan yang relevan . menggunakan teknik statistik atau algoritma pembelajaran mesin untuk menganalisis data dan menemukan insight.

4. Penafsiran(interpretation): setelah proses analisis maka hasil perlu ditafsirkan untuk mengambil keputusan atau memebuat kebijakan .

2. sistem rekomendasi produk pada toko online.
