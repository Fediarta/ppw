# Pencarian dan Penambangan web


## Pengertian web mining


Web Mining adalah Metode untuk  menemukan dan mengekstrak informasi dari internet menggunakan teknik penambangan data. web mining menerapkan teknik Data Mining untuk menggali dan memperoleh informasi otomatis dari data yang tersimpan di web. namun, web mining berbeda dengan data mining karena  informasi atau data web umumnya bersifat tidak terstruktur dan tersebar diberbagai sumber. Istilah web mining pertama kali dikenalkan oleh Etzioni Oren pada tahun 1996.


## Jenis - Jenis Web Mining

Web Mining  dibagi menjadi 3 bagian utama :

###  Web Content Mining

Web content Mining adalah suatu langkah otomatis untuk menemukan informasi yang berguna atau dibutuhkan dari dokumen atau data. Teknik Web Content mining berfokus pada Ekstraksi informasi dari isi (content) web, seperti Teks(Artikel,deskripsi,komentar), gambar(foto,ilustrasi), Audio(rekaman suara), Video(streaming clip), Metadata dan Hyperlink. Ada 2 pendekatan yang umum dilakukan :

1.dengan cara menambang langsung terhadap data yang ada.

2.dengan cara melakukan pencarian dan meningkatkan hasil pencarian seperti search engine.


#### Contoh Content Mining


1.Klasifikasi Dokumen

    tujuan: untuk mengkategorikan dokumen atau gambar yang belum pernah dilihat kedalam kelas seakurat mungkin.

    metode klasifikasi: Naive Bayes, Support Vektor Machines,Jaringan saraf tiruan,transformers.

2.pengelompokan konten(content clustering)

    pengelompokkan dokumen dengan mengukur kesamaan antar dokumen, dalam satu kelompok lebih mirip satu sama lain kemudian kelompok lain dengan dokumen berbeda antar satu sama lain.

    metode yang digunakan algoritma k-means ,pengelompokkan hierarkis, s-bert

3.Analisis Sentimen

    mengklasifikasikan teks yang diberikan pada tingkat dokumen,kalimat, atau fitur/atribut.


4.Ekstraksi Informasi 

    pengambilan informasi terstruktur secara otomatis dari konten web yang tidak terstruktur atau semi- struktur dari isi web

### Web Structure Mining

Web Structure Mining adalah teknik yang dimanfaatkan untuk mempelajari pola struktur link dari hyperlink sehingga diketahui hubungan antara suatu halaman web dengan halaman web lainnya. kemudian dari situ dapat dibangun  rangkuman website . kategori ini dari web mining berfokus pada penggalian informasi dari isi (content) yang disajikan web.


### Web Usage Mining 

Web Usage Mining adalah metode yang berfokus untuk analisis pada pola (pattern) dari pengguna dalam mengakses halaman-halaman web yang ditandai dari log, click,stream,cookies, dan query. manfaatnya untuk melakukan perubahan halaman berdasarkan profil pengguna,menentukan ketertarikan pelanggan terhadap produk dan menentukan target market yang sesuai.contoh dari teknik ini yaitu product recomendasi produk yang paling di sukai oleh pengguna berdasarkan data perilaku ,preferensi tau kesamaan dengan pengguna lain, personalized search (pencarian yang dipersonalisasikan) pencarian yang disesuaikan perilaku ,preverensi 



## Proses dalam Web mining

1.Pengumpulan data (Data Collection) : data diambil dari berbagai sumber diweb, seperti halaman web, file log server, media sosial, dll.

2.Preprocessing (persiapan data): pembersihan data dan proses agar format data sesuai yang dibutuhkan. contohnya seperti penghapusan data yang tidak relevan,mengatasi duplikasi,atau mengubah format.

3.Eksplorasi Data (Data Explorasi) : digunakan untuk mengidentifikasi pola atau hubungan yang relevan . menggunakan teknik statistik atau algoritma pembelajaran mesin untuk menganalisis data dan menemukan insight.

4.Penafsiran(interpretation): setelah proses analisis maka hasil perlu ditafsirkan untuk mengambil keputusan atau memebuat kebijakan .


## Penerapan Web Mining

1.Mesin pencari web (google, yahoo) digunakan untuk mengidentifikasi halaman web.

2.sistem rekomendasi produk pada toko online.

3.analisis sentimen  dan opini publik di media sosial dan portal berita.

4.pengomtimalan halaman web berdasarkan perilaku pengunjung.
